# 每日佳句 Daily Quotes

每天一句中英文名人佳句,永久循環的純靜態網站。

- 開啟 `index.html` 即可使用,或部署到 GitHub Pages / 任何靜態主機
- 每天依日期自動換句;每一輪(句數天)每句恰好出現一次,輪與輪之間順序不同
- 新增句子:在 `quotes.js` 陣列加一行 `{ zh, en, by }`

## 國中會考考古題練習

`exam/` 資料夾是獨立的考古題練習網站（開啟 `exam/index.html`）：依科目／年度篩選、作答後顯示解析、錯題本、標記複習、隨機順序，紀錄存在瀏覽器 localStorage。題庫在 `exam/questions.js`，目前只有示範題。
