## 計分方式

- 第 49 題:各選項獨立判定,答錯 k 個(漏選、多選都算)得 4×(n−2k)/n,低於 0 以 0 計,全未作答 0 分。
- 填充/簡答:與評分原則「滿分參考答案」完全相同(不分大小寫、忽略前後標點與多餘空白)給滿分;空白依評分原則 0 分;其他一律列「待評」(可能 1 分或 0 分),不算 0 分。
- 中譯英、作文:只提供原題,紙筆作答,成績頁標「紙筆作答,網站未評分」,不算 0 分,也不列入網站分數。
- 成績頁只顯示已計分部分的得分與滿分,不顯示整卷總分。分母只計已判定的題目:空白得 0 分、計入分母;已作答但待人工評閱的格子,滿分不列入分母。例:111 年 47(A)(B) 空白 → 6 / 72;47(B) 已作答待評 → 8 / 70。
